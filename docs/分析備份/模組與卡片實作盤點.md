### 1.2 勝負條件

**勝利**（3 個 flag 全達成）：
- `mansion_truth_revealed` → 揭開赫斯利洋房的真相
- `survivor_rescued` → 救出被困的倖存者
- `escaped_mansion` → 在暴風雨封路前活著離開

**失敗**：
- 30 大回合內未達成勝利
- 全體隊員倒下

### 1.3 開場敘事

> 一封沒有署名的信將你們引向荒廢多年的「赫斯利洋房」。三十個大回合後，進山的道路將被暴風雨徹底切斷 — 你們必須在那之前查明一切。

## 6. 結論

**現況**：模組劇情**敘事/數值資料 100% 備齊**（19 tile / 13 event / 5 battle / 4 ending），但**邏輯啟用率約 55%**：
- ✅ 完整可玩：MapExpand / 移動 / 行動卡出牌 / 事件結算（含 transformTile） / 裝備 / ORBIT
- ❌ 待開工：戰鬥子場景 / 結局觸發 / 同伴 AI / 完整 TurnLoop / TileProgress UI / 訊息氣泡

**最小可通關** demand 順序：Task 12 → Task 13 → Task 14（剩 ~40-50h Phase 2-3 工作）。
