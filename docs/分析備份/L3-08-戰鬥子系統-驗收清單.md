## L2 Godot 手測 14 步腳本

### 前置

- F5 跑遊戲
- 走到任意觸發 `triggerBattle` 的事件 — 最容易：點 ORBIT 中第 1 張 ClassA 卡 `mansion-entrance` → 結算 failure 路徑（如骰子很差）→ trigger `trespasser` 戰鬥
  - 或直接 console 改 `_gameState.PendingBattleId = "trespasser"` 後觸發 OnEventResolved
- 戰鬥子場景應淡入

### Step 1：戰鬥啟動（規格 §4.5 區塊 1 / 2）

| # | 動作 | 預期 |
|---|---|---|
| 1.1 | 戰鬥對話框開出 | 標題「戰鬥」；視窗大小 1100×900 |
| 1.2 | 確認頂部立繪區 | 玩家+同伴 立繪（人物A.png + 人物B.png）置中於左半邊；敵方 placeholder ×3 紫色矩形置中於右半邊 |
| 1.3 | 確認中部 HP 條 | 我方：艾絲黛 [HP bar 綠] 14/14、AP 3/3、同伴 多米尼 [HP bar 棕] 12/12；敵方：洋房闖入者 [HP bar 綠] 15/15 + 描述 + 「情報不明」 |
| 1.4 | 確認 STEP 卡片區 | STEP 1 兩格（我方/敵方）都灰邊框 + 「—」；STEP 2 五圓點全灰 |

### Step 2：Phase A 遭遇判定

| # | 動作 | 預期 |
|---|---|---|
| 2.1 | 點「擲骰判定」 | 顯示擲骰公式 + Tier；STEP 1 紅邊框出現在「我方」（Advantage / Normal）或「敵方」（Ambushed）；STEP 2 圓點依 Reveal 等級切亮 |
| 2.2 | 戰鬥日誌右側 | 出現「遭遇檢定 X (...) vs TN Y → 優勢/正常/劣勢...」訊息 |
| 2.3 | （若 Ambushed）自動切到敵方反應 | 不應出現 Response Dialog（我方無 AP 反應）→ 直接走 Phase C，敵方規畫顯示 |

### Step 3：Phase B 玩家行動

| # | 動作 | 預期 |
|---|---|---|
| 3.1 | 確認基本行動列表 | 5 個 entry：基本攻擊 / 防禦 / 觀察 / 重整位置 / 撤退；每 entry 含名稱+「免費」+公式+紅色「使用」按鈕 |
| 3.2 | 點「基本攻擊」使用 | 敵 HP 下降；戰鬥日誌新增「基本攻擊：X」；Basic 按鈕變灰（每回合 1 次） |
| 3.3 | 同回合再點任何 Basic | 提示「（本回合 Basic 行動已用過）」；不執行 |
| 3.4 | 點「結束本回合」 | 階段切 Phase C；自動規畫敵方行動 |

### Step 4：Phase C 敵方反應

| # | 動作 | 預期 |
|---|---|---|
| 4.1 | 敵方規畫 | 戰鬥日誌「敵方動作：XXX — 鎖定 Player 1。」 |
| 4.2 | 出現 Response Dialog | 紅邊框「敵方行動 · XXX」+ 5 反應選項列表（承受/迴避/格擋/反擊/反射） |
| 4.3 | 反射選項應 disabled | Phase 2 無反射卡資料 |
| 4.4 | 點「迴避（1 AP）」 | 結算閃避；玩家 AP -1；切回 Phase B 進下一回合 |

### Step 5：同伴戰鬥輔助 3 種

| # | 動作 | 預期 |
|---|---|---|
| 5.1 | 確認「同伴輔助（每戰 1 次）」section | 3 entry：攻擊加乘 / 行動輔助 / 抵擋傷害（蓄勢）；每 entry 含「同伴 1 AP」cost |
| 5.2 | 點「攻擊加乘」使用 | log「同伴啟動『攻擊加乘』」；該按鈕變灰 |
| 5.3 | 下次基本攻擊命中時 | 敵 HP 下降量 +2（對照無加乘的傷害） |
| 5.4 | 點「行動輔助」使用 | log「同伴啟動『行動輔助』」；該按鈕變灰 |
| 5.5 | 下次任意擲骰（攻擊 / 迴避 / 反擊） | total +2，較易命中 / 閃避 |
| 5.6 | 點「抵擋傷害（蓄勢）」使用 | log「同伴啟動『抵擋傷害』」；該按鈕變灰 |
| 5.7 | 結束本回合，敵方攻擊時 | **不應出現 Response Dialog**；直接 log「同伴 X 代受 N 傷害（蓄勢消耗）」+ 同伴 HP 下降，玩家 HP 不降 |

### Step 6：Vulnerable（雙 1 / CritFail）

| # | 動作 | 預期 |
|---|---|---|
