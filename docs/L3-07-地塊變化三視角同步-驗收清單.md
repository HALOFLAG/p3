## 完整三視角同步流程圖

```
玩家點 ORBIT village-inquiry → EventResolutionDialog 結算
  ↓
MainBootstrap.OnEventResolved
  ↓
worldMap.BeginEventBatch()  ←── eventDepth=1
  │
  ├─ 套 outcome.Effects（event-side）：
  │    EffectHandler.Apply 各 effect → state mutate
  │    NotifyWorldMapAfterEffect → 對應 NotifyXxx
  │
  ├─ ApplyTileSideTransformationsForEvent（tile-side）：
  │    1. 抓 PreEffectSnapshot（OLD terrain）
  │    2. MapService.TryTransformTilesForEvent
  │       → registry 查 village-inquiry 規則
  │       → 找 village-store 在 (4,5) 符合
  │       → EffectHandler.ApplyTransformTile(forest-path, X=5, Y=4)
  │       → state.TileMap[(5,4)].TileId = "forest-path"
  │    3. 對每個 change：
  │       worldMap.NotifyTileChanged(4, 5)        ← priority 10
  │       worldMap.NotifyTileTransformed(4, 5,    ← priority 70
  │           MapTerrain.Building, MapTerrain.Forest)
  │
worldMap.EndEventBatch()  ←── eventDepth=0 → flush
  ↓
依 priority 排序 emit：
  1. TileChanged(4, 5) → MainMapRenderer.OnTileChanged
       a. _tileNodes[4,5].SetTile(Forest, IsPlaced, IsExplored)  ← 主地圖 PNG 換
       b. UpdateParallaxScene()（若玩家在 (4,5)）              ← 場景立繪 SetTerrain
       c. 同事件 MinimapRenderer.OnTileChanged → QueueRedraw    ← 小地圖色塊換
  2. TileTransformed(4, 5, Building, Forest) → MainMapRenderer.OnTileTransformed
       a. _tileNodes[4,5].TriggerTransformAnimation()           ← 主地圖翻牌動畫
       b. AppendLog("地塊變化：(4,5) Building → Forest")        ← TURN LOG
```
