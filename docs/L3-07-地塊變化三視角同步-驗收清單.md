## 遊戲流程定位（Phase 2 簡化模型）

> 規格書 §3.1 定義的官方 5 階段循環 **MapExpand → Draw → Action → EventCheck → TurnEnd** 是 Phase 3 任務 14 (`TurnLoop`) 才會建。**Phase 2 走的是簡化版**：沒有正式的 `PhaseType` enum，只有 `InteractionMode { Idle, MapExpand, Move }` 表示當下互動狀態。

### 本驗收涉及的流程節點

| 規格階段 | Phase 2 對應 | 觸發點 | 主要動作 |
|---|---|---|---|
| **MapExpand** | `Mode = MapExpand` | TopBar「抽地塊」鈕 → `RequestDrawTile` → `BeginMapExpand` | 從 `state.TileDeck` pop tileId 進 `_heldTileId`；UI 進入「合法格高亮 + ghost 跟手」狀態 |
| 放置 | `Mode → Idle` | 點主地圖綠色合法格 → `TryPlaceHeldTile` | `state.TileMap[(col,row)] = PlacedTile{Level=Unknown}`；發 `TilePlaced` + `TileChanged` |
| **Draw**（與 TurnEnd 合併） | `AdvanceTurn` | TopBar「NEXT TURN ▶」 → `RequestAdvanceTurn` | 重置 AP/同伴 AP/FirstMove/FirstObserve；`DrawToHandLimit` 補手牌 |
| **Action** | 沒有獨立階段 | Idle 時隨時可動 | 移動 / 觀察 / 出牌 / 點 ORBIT 卡 — 全部用 `TryConsumeAp` 過 AP 閘 |
| **EventCheck** | 沒有獨立階段 | 玩家手動點 ORBIT ClassA 卡 | `EventResolutionDialog` → `OnEventResolved` → `EffectHandler.Apply` + `ApplyTileSideTransformationsForEvent` |

### 卡名顯示（本次新增）的更新時機

[RightPanel.cs](../scripts/Ui/RightPanel.cs) 三個 NEXT 預覽 slot 下方的卡名 label 由 `MainMapRenderer.DeckStatusChanged` signal（9 參數）驅動。`EmitHudSignals` 重發點：

| Signal 重發時機 | 對應的玩家動作 |
|---|---|
| `OnModeChanged` ([MainMapRenderer:740](../scripts/Map/MainMapRenderer.cs#L740)) | 抽地塊（Idle→MapExpand）、放置 / 取消（MapExpand→Idle）|
| `AppendLog` ([MainMapRenderer:1093](../scripts/Map/MainMapRenderer.cs#L1093)) | 幾乎所有 action（出牌 / 移動 / 結束回合 / ORBIT 結算）|
| `SwapWorldMap` ([MainMapRenderer:78](../scripts/Map/MainMapRenderer.cs#L78)) | MainBootstrap 切到 state-backed 後初次 sync |

→ 所以 L2 手測 Step 1.1 點抽地塊瞬間，slot1 會在同一幀切到「持有 / Building / 村內雜貨店」。

## 完整三視角同步流程圖

```
玩家點 ORBIT village-inquiry → EventResolutionDialog 結算
  ↓
MainBootstrap.OnEventResolved
  ↓
worldMap.BeginEventBatch()  ←── eventDepth=1
  │
  ├─ 套 outcome.Effects（event-side）：
  │    EffectHandler.Apply 各 effect → state mutate
  │    NotifyWorldMapAfterEffect → 對應 NotifyXxx
  │
  ├─ ApplyTileSideTransformationsForEvent（tile-side）：
  │    1. 抓 PreEffectSnapshot（OLD terrain）
  │    2. MapService.TryTransformTilesForEvent
  │       → registry 查 village-inquiry 規則
  │       → 找 village-store 在 (4,5) 符合
  │       → EffectHandler.ApplyTransformTile(forest-path, X=5, Y=4)
  │       → state.TileMap[(5,4)].TileId = "forest-path"
  │    3. 對每個 change：
  │       worldMap.NotifyTileChanged(4, 5)        ← priority 10
  │       worldMap.NotifyTileTransformed(4, 5,    ← priority 70
  │           MapTerrain.Building, MapTerrain.Forest)
  │
worldMap.EndEventBatch()  ←── eventDepth=0 → flush
  ↓
依 priority 排序 emit：
  1. TileChanged(4, 5) → MainMapRenderer.OnTileChanged
       a. _tileNodes[4,5].SetTile(Forest, IsPlaced, IsExplored)  ← 主地圖 PNG 換
       b. UpdateParallaxScene()（若玩家在 (4,5)）              ← 場景立繪 SetTerrain
       c. 同事件 MinimapRenderer.OnTileChanged → QueueRedraw    ← 小地圖色塊換
  2. TileTransformed(4, 5, Building, Forest) → MainMapRenderer.OnTileTransformed
       a. _tileNodes[4,5].TriggerTransformAnimation()           ← 主地圖翻牌動畫
       b. AppendLog("地塊變化：(4,5) Building → Forest")        ← TURN LOG
```
