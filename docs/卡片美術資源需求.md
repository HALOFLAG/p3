## 0. 美術製作流程與版權聲明

### 0.1 標準工作流程：人工草圖 + AI 完成構圖

本專案所有原創美術採用**人類設計師主導 + AI 工具輔助**的混合流程：

```
1. 使用者繪製初始草圖
   ├─ 構圖 / pose / 場景配置由人類設計師（haloflag）親自繪製
   ├─ 媒介：紙本掃描 / 數位繪圖（Procreate / Krita / PS）
   └─ 產出：sketch.png / sketch.psd（保留圖層）

2. AI 完成構圖
   ├─ 工具候選：Midjourney / Stable Diffusion / Flux / DALL-E
   ├─ 以草圖為 ControlNet / image-to-image 輸入
   ├─ 紀錄 prompt / model / seed / 參數
   └─ 產出：ai-output.png + 完整 prompt log

3. 後製整合
   ├─ 色調統一（套用專案 Palette：Paper / Ink / Gold）
   ├─ 細節修整 / 異常修正（手指 / 文字 / 邊緣）
   ├─ 切版 / 縮放（full 180×252 + compact 68×95）
   └─ 產出：final.png + final.psd（layered）
```

### 0.2 版權主張與 Steam 揭露

依此流程，**每件美術的版權主張**：

| 元素 | 版權狀態 |
|---|---|
| 構圖 / 設計 | ✅ 由人類草圖確立 → 享有版權 |
| AI 完成的細節 / 上色 | ⚠️ AI 為工具，但 Steam 仍視為 AI 內容 |
| 後製整合 | ✅ 人類創作 |
| 整體 | 享有版權，但**須揭露使用 AI 工具** |

**Steam Content Survey 揭露要求**（依 [版權與AI內容政策分析](./版權與AI內容政策分析.md) §2）：
- ✅ 必須勾選 **Pre-Generated AI 內容**
- ✅ 揭露文字範例：「角色立繪、場景圖、卡牌插圖採人工草圖 + AI 工具（Midjourney/SD）完成構圖，最終由人類後製整合。所有素材均不含侵權內容。」
- ⚠️ Steam 商店頁會出現「This game uses AI-generated content」標籤 → 此為已知接受成本

### 0.3 第三方素材處理

部分素材可能來自外部來源（字型、音效搬美術範例等），需明確分類：

| 來源類型 | 必備證明 | 例 |
|---|---|---|
| **委外 / 委託創作** | 委託合約 + invoice + 版權轉讓條款 | 某美術師繪製主視覺 |
| **購買 stock asset** | 購買收據 + license 條款截圖 | Itch.io / Envato 商業包 |
| **CC0 / Public Domain** | 來源頁面 URL 截圖 + 下載日期 | OpenGameArt / Pixabay CC0 |
| **CC BY 系列**（需署名） | URL + 作者署名 + license 文字 | Wikipedia 圖片 / Flickr CC BY |
| **自家手繪 + AI 完成**（本專案主流程） | 草圖檔 + AI prompt log + 後製 PSD | 全部模組原創美術 |

**禁止使用**：
- ❌ 來源不明 / 無授權的圖片
- ❌ 受智慧財產保護的角色 / 場景（迪士尼 / 任天堂 / 動漫等）
- ❌ AI 直接抄襲特定藝術家畫風（具體 in-the-style-of 商業藝術家）
- ❌ 訓練資料含明確侵權的 AI model（如未授權 fan art LoRA）

### 0.4 來源記錄要求（**強制執行**）

**每一項美術資產上架前必須**有完整來源記錄。維護位置：

```
art/
├── SOURCES.md              ← 中央來源 manifest（必維護）
├── tiles/
│   ├── forest.png
│   ├── forest.png.source/  ← 對應子目錄
│   │   ├── sketch.png      ← 原始草圖
│   │   ├── ai-prompt.txt   ← AI prompt log
│   │   ├── final.psd       ← layered 後製檔
│   │   └── README.md       ← 流程備註
│   └── ...
├── portraits/
│   └── (相同結構)
└── ...
```

**`art/SOURCES.md` 必填欄位**（範本見附錄 C）：

| 欄位 | 範例 |
|---|---|
| 檔案路徑 | `art/portraits/scholar/neutral.png` |
| 來源類型 | sketch+ai / commission / stock / cc0 / self-drawn |
| 創作者 | haloflag |
| AI 工具（若用） | Midjourney v6.1 / Stable Diffusion XL |
| 草圖檔 | `art/portraits/scholar/neutral.png.source/sketch.png` |
| Prompt | `art/portraits/scholar/neutral.png.source/ai-prompt.txt` |
| 授權證明 | (無，自有) / `licenses/itch-pack-2026-03.pdf` |
| 完工日期 | 2026-XX-XX |
| Steam 揭露分類 | Pre-Generated AI / Original / Licensed |

### 0.5 上架前 audit checklist

正式 ship 前 1 週執行：

- [ ] 所有 art/*.png 都有對應 `art/SOURCES.md` 條目
- [ ] AI 流程的素材都有 `*.source/` 子目錄含 sketch + prompt
- [ ] 委外素材都有合約 + invoice 在 `licenses/` 目錄
- [ ] 字型授權確認商用 OK（Noto / 思源 / 自費購買）
- [ ] 音效 / BGM 來源同上
- [ ] Steam Content Survey 草稿準備（揭露 AI 使用 + 細節）
- [ ] 法務 / 自我審查 pass（無侵權嫌疑、無受保護 IP）

### 0.6 模組製作者（社群）注意事項

當未來開放 Workshop 上傳時，模組製作者上傳含美術的模組需：

- 同意 UGC Agreement 並聲明擁有 / 已授權
- 模組 manifest 加 `aiContent: true/false` 欄位
- 模組附帶 `SOURCES.md`（建議但非強制）
- 違規模組由 DMCA / 玩家舉報觸發下架

詳見 [版權與AI內容政策分析.md](./版權與AI內容政策分析.md) §5。

## 13. 預算估計（工時 + 行情區間，不列 NTD 金額）

下表以 **3 條路徑**估計，皆不含管理 / 整合成本。

### 13.1 人工草圖 + AI 構圖混合路徑（**本專案標準路徑**）

依 §0 工作流程，每張美術需 3 個階段工時：草圖 → AI 構圖 → 後製。

| 類別 | 張數 | 草圖工時/張 | AI 工時/張 | 後製工時/張 | 總工時 | 備註 |
|---|---|---|---|---|---|---|
| 卡牌 full（行動+事件+裝備+戰鬥+結局） | 88 | 0.5h | 0.3h | 0.4h | ~106h | 草圖以簡筆勾形構圖；AI 完成上色與細節 |
| 卡牌 compact | 79 | 0.1h | 0.1h | 0.1h | ~24h | 從 full 縮製 + 重新構圖簡化 |
| 角色立繪 × 21 | 21 | 1.0h | 0.5h | 0.5h | ~42h | 多表情需草圖統一 pose；ControlNet 確保一致性 |
| 場景立繪 mid+near × 12 | 12 | 0.8h | 0.5h | 0.4h | ~20h | 三層需手動拆分 |
| UI 圖示 × 25 | 25 | 0.3h | 0.2h | 0.3h | ~20h | 簡化向量風；AI 生成後常需重繪 |
| 結局 / 序幕全螢幕 × 5 | 5 | 1.5h | 0.5h | 1.0h | ~15h | CG 級大尺寸 |
| **合計** | **230** | - | - | - | **~227h** | 約 28 個工作天（單人 8h/天） |

> **比 v1.0 純 AI 路徑（~119h）多約 90h**：增加部分為人類草圖時間，換來：
> - 構圖原創性（享有版權）
> - 風格一致性（草圖統一 pose / 視角）
> - 角色面部 / 手部準確（AI 直出常出錯）
> - Steam 上架責任歸屬清楚（仍需揭露 AI 使用）

**工具與來源紀錄**：
- AI 模型訂閱費：月費級別（Midjourney $30/月 / SD 自架）
- 每張完工後寫入 `art/SOURCES.md`（範本見附錄 C）
- 保留 `*.source/` 子目錄：sketch.png + ai-prompt.txt + final.psd

### 13.1.1 純 AI 直出路徑（**不採用**）

僅供對照參考。**本專案不採用** — 因：
- 構圖無人類創作 → 版權歸屬法律灰色地帶
- 角色面部 / 手部錯誤率高 → 後製成本反而高
- 風格一致性差 → 多張角色看起來不像同一個畫師
- Steam AI 標籤效應同樣存在，但少了人類草圖的「原創性說服力」

### 13.4 路徑比較（本專案決策）

| 路徑 | 總工時 | 一致性 | 版權主張 | Steam 揭露 | 風險 | 採用 |
|---|---|---|---|---|---|---|
| **人工草圖 + AI 構圖（§13.1）** | **~227h** | 高（草圖統一） | ✅ 構圖原創 | Pre-Generated AI | 中（後製需細心） | **✅ 本專案採用** |
| 純 AI 直出（§13.1.1） | ~119h | 需 LoRA 維持 | ⚠️ 灰色 | Pre-Generated AI | 高（一致性 / 細節錯誤） | ❌ 不採用 |
| 委外（§13.2） | 視合約 | 高（同一畫師） | ✅ 委託合約 | Original | 中（預算 / 進度） | 🟡 預算允許時補強 |

**採用「人工草圖 + AI 構圖」的關鍵理由**：
1. 工時可控（~227h vs 自繪 391-759h）
2. 構圖**人類原創**，版權有底氣
3. 比純 AI 直出更精準、一致
4. Steam 揭露為 Pre-Generated AI 是已知接受成本
5. 留下 `art/SOURCES.md` 完整鏈條，DMCA 反通知有底氣

**未來擴充**：商業版本若銷量良好，可委外重繪重要角色 / 結局 CG 強化品牌（升級為 §13.2 委外路徑）。

### 16.1 art/SOURCES.md 維護規則

| 項目 | 必填？ | 說明 |

| dateCompleted | ✅ | 完工日期 YYYY-MM-DD |
| aiTool | ⚠️ | 若 sourceType 含 ai 必填（Midjourney v6.1 等） |
| sketchPath | ⚠️ | 若 sourceType=sketch+ai 必填 |

### 16.2 半自動 audit 工具（`tools/ArtSourceAudit`，建議建立）

CLI 工具，啟動時：
1. 掃 `art/**/*.png`
2. 對每張 PNG 找對應 `art/SOURCES.md` 條目
3. 檢查 `.source/` 子目錄存在性
4. 檢查 `licenses/` 引用檔存在
5. 列出**缺失的**項目（紅燈）+ **不完整的**項目（黃燈）

範例輸出：
```
✅ art/tiles/forest.png — sketch+ai (Midjourney v6.1)
✅ art/portraits/scholar/neutral.png — sketch+ai
🟡 art/portraits/scholar/serious.png — 缺 ai-prompt.txt
🔴 art/cards/event/empty-room.full.png — SOURCES.md 無此條目
🔴 art/scenes/forest/mid.png — 缺 .source/ 子目錄
```
