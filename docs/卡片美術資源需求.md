## 15. 實作建議

### 15.1 v1 placeholder（Phase 2 Task 7 後續）

- 行動 / 事件 / 裝備 / 戰鬥 / 結局 / 序幕卡：以 `Palette` 純色 `ColorRect` + `Label` 取代美術，已實作於 `HandDock` / `EquipmentCardView`。
- 場景立繪：mid / near 兩層用程式生成色塊 placeholder（任務 8 Stage 1）。
- UI 圖示：以 emoji 或 `Label` 取代（屬性 4 / 行動類型 4）。
- 角色立繪：以姓名首字 + 純色背景圓形 placeholder。

### 15.2 v2 分批產製順序

1. 先補 P0 的 **場景立繪 12 張**（任務 8 Stage 2 阻擋）
2. 再補 P0 的 **行動卡 / 裝備卡 compact 65 張**（高頻 UI）
3. 再補 P1 的 **行動卡 / 裝備卡 / 事件卡 full 79 張**
4. 補 P2 的角色立繪 21 張（含表情變化）
5. 最後補 P3 的結局 / 序幕 / UI 雜項

### 15.3 風格基準

- 美術風格基準：**手繪紙質 + 微膠片顆粒**（沿用 `Palette` Paper / Ink / Gold 配色）
- 卡片邊框：1.5px Gold（規格書 §6.2）
- 共通字型：中文標題建議思源宋體 / 思源黑體（可商用），需置入 `art/fonts/`

### 15.4 命名規範對齊

- 統一使用 kebab-case（`scholar-deduction.full.png`）
- full / compact 用副檔名前綴：`{id}.full.png` / `{id}.compact.png`
- 角色多表情用子目錄：`portraits/{character}/{expression}.png`
- 場景三層用子目錄：`scenes/{terrain}/{far|mid|near}.png`（far 實作以 region 裁切免做）
